{{ icon('tablet', 18) }} Books on your e-reader

KOReader can download books automatically into a folder on your e-reader. Choose what it should keep in sync: your whole library, or only a selection.

{% for id, label, url in sync_feeds %}
{{ label }}{% if id == 'sync-marked' %} · {{ device_count }} marked, use “Send to e-reader” on a book{% if device_count %} · show{% endif %}{% endif %} {{ copy_field(id, url) }}
{% endfor %} {% call howto() %}
  1. In KOReader’s file browser, open Search → OPDS catalog, tap + and add a catalog with one of the addresses above and your Bookshelf username and password. Enable Sync catalog.
  2. In the OPDS catalog menu, choose the folder for synced books.
  3. Run Sync (for example by long-pressing the catalog). KOReader downloads the books added since the last sync, newest first.

KOReader downloads at most 50 books per sync by default. Raise that limit for the first sync of a large library, or use Force sync. Books removed in Bookshelf stay on the e-reader.

{{ icon('chart', 18) }} Reading statistics

Sync KOReader’s reading statistics to see your reading time, streaks and activity.

WebDAV address {{ copy_field('webdav-url', webdav_url) }}
{% call howto() %}
  1. In KOReader’s file browser, open Cloud storage, tap + and add a WebDAV server with the address above and your Bookshelf username and password. Leave the folder empty.
  2. Open a book, then Tools → Reading statistics → Settings → Cloud sync, pick that server and choose its main folder.
  3. Run Synchronize now (or let KOReader sync automatically). Repeat steps 1–2 on each device; KOReader merges their statistics.
{% endcall %}

Advanced: edit the configuration as JSON

This is your file {{ reader_config_file }} in the data directory; you can also edit it there directly. It is merged on top of the current defaults, so include only what you want to change. The bar editor above writes its layout part.

  • themes, settings.fonts, settings.sections and their controls merge by id (controls by key): a new id adds an entry, an existing id changes it, and "hidden": true removes it. layout.top / layout.bottom replace the default lists.
  • Example: {"settings": {"sections": [{"id": "text", "controls": [{"key": "fontSize", "max": 48}]}]}} raises the largest font size to 48.
